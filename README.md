# Assignment 11: Build a Product Grid

## 📌 Project Overview
This project is a product grid webpage created using HTML and CSS. It displays multiple products in an organized and attractive layout with product images, names, descriptions, prices, and buttons.

## ✨ Features
- Displays six product cards.
- Shows product images, names, and descriptions.
- Displays product prices in Indian Rupees.
- Includes Add to Cart buttons.
- Uses CSS Grid for layout.
- Includes hover effects on product cards.
- Responsive design for desktop, tablet, and mobile devices.
- Uses a clean pastel colour theme.

## 🛠️ Technologies Used
- HTML5
- CSS3
- CSS Grid
- Media Queries

## 🚀 How to Run the Project
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in a browser.
4. Explore the product grid layout.

- Learned to create layouts using CSS Grid.
- Understood responsive design using media queries.
- Applied hover effects and card styling.
